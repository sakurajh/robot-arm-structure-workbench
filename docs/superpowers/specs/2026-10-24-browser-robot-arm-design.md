# 浏览器 3D 机械臂展示系统设计

日期：2026-10-24

## 目标与用途

构建一个用于结构教学演示的浏览器 3D 机械臂展示系统。用户能够观察机械臂整体与内部传动结构，并通过爆炸图、透明外壳和剖面图理解主要总成之间的装配关系。

最终成品是可双击、离线使用的单个 HTML 文件。使用者不需要安装 Node.js、启动开发服务器或访问网络。

## 已确认约束

- 使用内置程序化演示模型，不要求用户提供 GLB、glTF 或 STEP 文件。
- 模型用于结构教学示意，不宣称具有工程级 CAD 的尺寸或装配精度。
- 使用 Three.js，所有运行依赖打包进 HTML，不加载 CDN 或其他外部资源。
- 桌面浏览器优先，同时保证窄屏下控制面板可用。
- 不包含关节运动仿真、物理仿真、在线部署、用户账户或后端服务。

## 视觉与布局

采用深色工业风全屏 3D 场景。机械臂使用米白色外壳、橙色关节与金属内构，配地面网格、柔和阴影和清晰轮廓光。

页面由中央 3D 视口、左侧总成层级和右侧模式控制面板组成。左侧用于定位底座、回转台、肩部、大臂、肘部、小臂、腕部与末端执行器；右侧用于切换展示模式和调整参数。窄屏时面板可折叠，避免遮挡主要模型。

## 演示模型

模型按独立零件组构建，主要总成包括：

1. 固定底座与回转支承。
2. 回转台、肩部电机与肩部外壳。
3. 大臂、肘部电机与减速器。
4. 小臂、传动轴与腕部总成。
5. 末端执行器、夹指与连接法兰。

内部电机、减速器、轴承和传动轴采用简化但可辨识的几何结构。每个可点选零件具有稳定标识、中文名称、所属总成和简短用途说明。

## 核心展示模式

### 完整装配

默认显示完整机械臂。用户可以旋转、缩放和平移相机，点击零件高亮并查看名称与用途，也可一键恢复默认相机和展示状态。

### 爆炸图

各总成沿预定义的装配方向分离，避免仅向外随机散开。爆炸距离由 0–100% 滑块控制，并显示当前数值；模式切换采用平滑过渡。用户仍可旋转相机和点选零件。

### 透明外壳

仅外壳零件逐渐变为透明，内部电机、减速器和传动结构保持不透明。透明度滑块显示实时百分比。透明材质采用适合多层外壳观察的深度与双面设置，尽量减少排序造成的遮挡闪烁。

### 剖面图

通过 Three.js 局部裁剪平面实时移除模型一侧，暴露内部结构。用户可选择 X、Y 或 Z 剖切方向，并通过滑块调整剖切位置与数值。剖切面提供清晰的视觉参考，退出模式后完整恢复材质与几何显示。

## 交互与状态

统一状态包含当前模式、爆炸比例、外壳透明度、剖切轴、剖切位置、选中零件和面板展开状态。

OrbitControls 提供旋转、缩放与平移，缩放以观察目标为中心。Raycaster 负责零件拾取；选中时显示高亮与说明。复位操作恢复默认模式、参数、选择和相机。

滑块在单次拖动中提供明显反馈与数值回显。模式切换和爆炸位移使用短时平滑动画，参数拖动保持即时响应。

## 技术结构

- Three.js 负责场景、几何、材质、光照、裁剪和渲染。
- OrbitControls 负责相机操作。
- Raycaster 负责鼠标或触控拾取。
- 程序化模型模块定义零件、层级、教学说明和爆炸方向。
- 展示控制器统一更新模式与零件变换，避免各模式相互覆盖状态。
- 界面模块绑定按钮、滑块、层级树和零件说明。
- 构建阶段将 JavaScript、CSS、Three.js 与 OrbitControls 内联到最终 `index.html`。

运行时不进行网络请求，不依赖 `localStorage`，不需要 Service Worker，也不要求服务器特性。

## 性能与兼容性

使用抗锯齿、色调映射和受控阴影质量。像素比设置合理上限，避免高分屏无意义地增加渲染负担。模型复用几何与材质，动画仅在场景活跃时持续更新。

目标为支持 WebGL2 的现代桌面 Chrome 和 Edge。若 WebGL 初始化失败，页面显示可理解的错误提示，而不是保留空白画布。

## 验收与验证

交付前执行以下检查：

1. 检查最终 HTML 中不存在 CDN、远程脚本或其他运行时外部依赖。
2. 通过 `file://` 实际双击等价方式打开成品，确认无需服务器。
3. 逐项测试完整装配、爆炸图、透明外壳和 X/Y/Z 剖面模式。
4. 测试所有滑块、数值回显、零件点选、总成定位、相机控制与复位。
5. 检查浏览器控制台无应用错误，网络面板无外部请求。
6. 截图检查默认场景、三种模式和窄屏布局，确认模型可见、面板不遮挡关键内容。
7. 检查 WebGL 不可用时是否有明确提示。

## 交付物

- `index.html`：可独立离线运行的完整成品。
- 预览截图：用于快速查看默认场景和主要模式，不是运行所必需的文件。

最终用户只需保留并双击 `index.html`。
